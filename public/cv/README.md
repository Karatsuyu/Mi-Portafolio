# CV PDF - Instrucciones

## Ubicación del archivo
Coloca tu CV en formato PDF en esta carpeta con el nombre:
**`CV-Julian-Gutierrez-Tabares.pdf`**

## Cómo crear el CV

### Opción 1: Usar el template de CVDocument.tsx
El archivo `components/cv/CVDocument.tsx` contiene toda la estructura y contenido del CV.
Puedes usar herramientas online para generar el PDF:

1. Ve a https://react-pdf.org/repl (REPL oficial de react-pdf)
2. Copia el contenido de `components/cv/CVDocument.tsx`
3. Genera el PDF
4. Descárgalo y guárdalo aquí como `CV-Julian-Gutierrez-Tabares.pdf`

### Opción 2: Usar Google Docs/Word
1. Abre Google Docs o Microsoft Word
2. Usa el template Harvard adaptado (ver documento adjunto en la especificación)
3. Llena con tu información:
   - **Header**: Julián Estiven Gutiérrez Tabares - Tecnólogo en Desarrollo de Software
   - **Contacto**: Email, teléfono, GitHub, LinkedIn
   - **Skills** (arriba después de contacto)
   - **Educación**: Universidad del Valle
   - **Proyectos** (8 proyectos destacados)
   - **Experiencia Práctica**
   - **Certificaciones**
   - **Idiomas**
4. Exporta como PDF
5. Guarda aquí como `CV-Julian-Gutierrez-Tabares.pdf`

### Opción 3: Usar Canva o Figma
1. Usa plantillas profesionales de CV
2. Diseño minimalista con colores morado (#7042f8) y negro
3. Máximo 2 páginas
4. Exporta como PDF
5. Guarda aquí como `CV-Julian-Gutierrez-Tabares.pdf`
